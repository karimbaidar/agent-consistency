# False-Success Benchmark

The benchmark is a deterministic scenario suite where a raw agent reports
success even though the business outcome is false.

Current generated result:

> raw caught 0/6; agent-consistency caught 6/6

The number comes from `benchmark/results.md`, generated by the harness:

```bash
python -m benchmark.run --write-results benchmark/results.md
```

## Scenario Categories

- `outcome_verification`: provider status, partial write, wrong entity, and
  swallowed tool error cases
- `state_freshness`: stale policy snapshot case
- `handoff_contract`: missing required handoff fact case

These results describe this repository's deterministic benchmark only. They are
not a universal claim about every possible agent workflow.
